tuhi.

tuhi — Māori: to write, to inscribe, to record

A fast, calm editor that isn't afraid of big files.

An open-source text and Markdown editor for Windows, macOS and Linux. It opens multi-gigabyte files without flinching, and Markdown documents render as you write — click any block to edit it in place, no preview pane to manage.

View on GitHub Roadmap

Open source · MIT · approaching v1.0 · Windows, macOS & Linux

>Big files, no fear

Open and scroll multi-gigabyte files with flat memory. Find, go-to-line and live filtering work at that scale, not just scrolling.

>Markdown you edit in place

Documents render by default; click any block to open just that block as raw Markdown, edit, and it re-renders. No separate preview pane to manage.

>Rich when it matters

Tables, syntax-highlighted code, Mermaid diagrams and KaTeX math, all rendered inline. The raw Markdown is always one keystroke away.

>Fast and keyboard-first

A command palette, the full set of editor shortcuts, and a UI that stays out of the way. Reach for the mouse only when you want to.

>Never lose work

Crash-safe: unsaved changes are journalled as you type and offered back if the app is ever killed. Saves are atomic — a failed write can't corrupt your file.

>Plain by nature

Your files stay plain .md and .txt on disk — no vault, no lock-in, no proprietary format. Just text, done well.
